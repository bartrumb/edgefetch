# Portable Hub Runtime & Storage Adapters (`hub/portable`)

## Overview
Self-hosted runtime entrypoints and Cloudflare-compatible binding adapters enabling EdgeFetch Hub to run outside Cloudflare Workers on Node.js (`portable-server.ts`, `node-adapters.ts`), backed by local SQLite/filesystem or remote Turso/libSQL HTTP D1 (`turso-d1.ts`), SigV4 S3 R2 (`s3-bucket.ts`), SSRF-hardened DNS-pinned outbound fetch (`safe-fetch.ts`), and `cloudflare:workers` runtime shims (`cloudflare-shim.ts`).

## Interface
- `PortableHubOptions` & `startPortableHub(opts?: PortableHubOptions)` — Starts the Node.js HTTP and `/agent/ws` WebSocket Hub server, returning `Promise<{ server, port, close }>` `[portable-server.ts:PortableHubOptions]` `[portable-server.ts:startPortableHub]`.

## Invariants
- `incomingToWebRequest` unconditionally overwrites `cf-connecting-ip` with `resolveTrustedClientIp(req, trustProxy)` (taking the rightmost valid IP literal from `x-forwarded-for` after stripping `:port` only when `trustProxy` is `true`), wraps `req` in a pull-driven paused `ReadableStream` (`safeNodeReqToWebStream`), strips all `x-forwarded-*` headers when `trustProxy` is `false`, validates `x-forwarded-proto` (`http`|`https`) and `x-forwarded-host` (valid hostname and port `1..65535`) when `trustProxy` is `true`, and rejects request targets not starting with `'/'` or equal to `'*'` with `400 Bad Request` `[portable-server.ts:incomingToWebRequest]`.
- `startPortableHub` sets `requestTimeout = 60_000`, `headersTimeout = 15_000`, and `maxConnections = 512`, closes and destroys incomplete request sockets (`!req.complete`) after flushing `>= 400` responses, binds `SAFE_FETCH` with `allowExplicitLoopbackUrls: true` and `SAFE_PUBLIC_FETCH` with `allowExplicitLoopbackUrls: false`, requires all four of `S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, and `S3_SECRET_ACCESS_KEY` before selecting `S3ArtifactBucket` over `NodeFsR2Bucket`, and rejects non-`/agent/ws`, malformed, or unauthorized HTTP upgrades (`404` / `400` / `401`) while destroying the socket `[portable-server.ts:startPortableHub]`.
- `NodeSqliteD1Database` tracks applied schema migrations idempotently via `_ef_migrations(name TEXT PRIMARY KEY)` and executes `batch()` inside `BEGIN IMMEDIATE ... COMMIT` (`ROLLBACK` on error) `[node-adapters.ts:NodeSqliteD1Database]`.
- `NodeFsR2Bucket` sanitizes keys via `safeRelPath` (rejecting paths resolving outside `resolve(rootDir)`), enforces `if-none-match: *` / `etagDoesNotMatch: *` conditional puts, and verifies `options.sha256` before writing `[node-adapters.ts:safeRelPath]` `[node-adapters.ts:NodeFsR2Bucket]`.
- `RawServerWebSocket` enforces RFC 6455 §5.1/§5.2/§5.5 framing (closing with `1002` on non-zero `RSV` bits, unmasked client frames, fragmented control frames, or control payloads `> 125` bytes), reassembles fragmented text frames up to `1_048_576` bytes (1 MiB, closing with `1009` `'message_too_big'`), caps pending outbound `pong` queue at `65_536` bytes (`1008`), truncates close reasons to 100 bytes, and throws `'websocket_closed'` on writes after close `[node-adapters.ts:RawServerWebSocket]`.
- `LocalAgentHubCoordinator` lowercases `host` and `siteId` keys across SQLite coordination tables, rate-limits `agent_ws_connected` and `agent_ready` activity-log entries per site/IP, clamps `hostHealth.listHosts(limit)` to `[1, 500]`, caps `getPortalState` events at `150`, and returns HTTP `426` from `asNamespace().get().fetch()` `[node-adapters.ts:LocalAgentHubCoordinator]`.
- `buildSigV4Headers` signs with `AWS4-HMAC-SHA256` (`s3/aws4_request`), decodes URI path segments via `safeDecodeURIComponent`, defaults `x-amz-content-sha256` to `'UNSIGNED-PAYLOAD'`, and excludes `host` from the returned header dictionary after signing; `S3ArtifactBucket.put` verifies optional `options.sha256` and returns `null` on `412`/`409` conditional write conflicts, while `head`/`get` return `null` on `404` and `delete` treats `404` as idempotent success `[s3-bucket.ts:buildSigV4Headers]` `[s3-bucket.ts:S3ArtifactBucket]`.
- `isPublicIpAddress` blocks all non-public IPv4 ranges (`IPV4_BLOCKLIST`), rejects zone-scoped IPv6 (`%`), and restricts IPv6 strictly to `2000::/3` global unicast outside `IPV6_BLOCKLIST` (rejecting IPv4-mapped `::ffff:0:0/96`); `createPublicOnlyLookup` resolves with `{ all: true, verbatim: true }`, settles at most once, and rejects if zero addresses resolve or any resolved address is non-public `[safe-fetch.ts:isPublicIpAddress]` `[safe-fetch.ts:createPublicOnlyLookup]`.
- `createSafeOutboundFetch` permits only `http:` and `https:`, rejects `101 Switching Protocols` (`upgrade`) and `CONNECT` responses while settling every request Promise on premature close/abort without uncaught stream errors, rejects non-public IP literals unless `allowExplicitLoopbackUrls === true` for `'127.0.0.1'` / `'localhost'` / `'[::1]'`, defaults `redirect` to `'manual'`, and under `redirect: 'follow'` caps hops at `5`, requires `https:` redirect targets, and strips `authorization`, `cookie`, and `x-api-key` across origins `[safe-fetch.ts:createSafeOutboundFetch]`.
- `TursoHttpD1Database` normalizes `libsql://` URLs to `https://.../v2/pipeline`, clones immutable `TursoPreparedStatement` instances on `bind()`, appends `{ type: 'close' }` to every pipeline batch, and throws on non-OK HTTP responses or statement `'error'` entries `[turso-d1.ts:normalizePipelineUrl]` `[turso-d1.ts:TursoPreparedStatement.bind]` `[turso-d1.ts:TursoHttpD1Database.executeRaw]`.

## Side Effects
- `portable-server.ts` creates `<dataDir>/hub.sqlite` plus local `<dataDir>/meta.sqlite`, `<dataDir>/search.sqlite`, and `<dataDir>/artifacts` (when Turso/S3 are not configured), binds an HTTP/WebSocket listener on `host:port`, and auto-starts on CLI entry when `process.argv[1]` ends with `portable-server.mjs` `[portable-server.ts:startPortableHub]` `[portable-server.ts:process.argv]`.
- `node-adapters.ts` polyfills `globalThis.crypto.DigestStream` if missing at module load, synchronously creates SQLite parent and R2 root directories (`mkdirSync`), opens WAL-mode `DatabaseSync` handles executing DDL migrations, performs async filesystem artifact I/O, and writes RFC 6455 handshake/frames over raw `Duplex` sockets `[node-adapters.ts:NodeDigestStream]` `[node-adapters.ts:NodeSqliteD1Database]` `[node-adapters.ts:NodeFsR2Bucket]` `[node-adapters.ts:LocalAgentHubCoordinator]`.
- `s3-bucket.ts` invokes WebCrypto `crypto.subtle` digest/HMAC operations and issues outbound `HEAD`, `GET`, `PUT`, and `DELETE` HTTP requests against S3 endpoints `[s3-bucket.ts:buildSigV4Headers]` `[s3-bucket.ts:S3ArtifactBucket]`.
- `safe-fetch.ts` allocates module-level `net.BlockList` instances (`IPV4_BLOCKLIST`, `IPV6_BLOCKLIST`), performs DNS lookups via `node:dns`, creates keep-alive `http.Agent` / `https.Agent` pools, and opens outbound TCP/TLS requests `[safe-fetch.ts:IPV4_BLOCKLIST]` `[safe-fetch.ts:createPublicOnlyLookup]` `[safe-fetch.ts:createSafeOutboundFetch]`.
- `turso-d1.ts` sends outbound HTTP `POST` JSON requests with optional `Bearer` authorization to Turso `/v2/pipeline` endpoints `[turso-d1.ts:TursoHttpD1Database.executeRaw]`.

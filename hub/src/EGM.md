# EdgeFetch Hub Runtime (`hub/src`)

## Overview

`hub/src` implements the thin Cloudflare Worker edge router (`edgefetch-hub`), Hibernating WebSocket Durable Object coordinator (`AgentHubDO`), Cloudflare Workflows (`CrawlWorkflow`, `IngestWorkflow`), self-hosted OAuth 2.1 + GitHub OAuth authorization server, Streamable HTTP Model Context Protocol (`/mcp`) server, `/admin` operator control center, `/v1/*` and Firecrawl/Tavily compatibility HTTP APIs, R2/D1 three-layer artifact & FTS5 search storage pipeline, and the `wasm-bridge.ts` WASI reactor host delegating pure-CPU HTML/PDF/JSON extraction, sanitization, jobs/ATS intelligence, storefront catalog diffing, BYO-LLM agent orchestration, and MCP federation to Go (`cmd/edgefetch-wasm` / `edgefetch-core.wasm`).

## Invariants

- **Constant-Time Secrets, Agent Isolation & Pre-Body Auth**:
  - Configured secrets (`CALLER_TOKEN`, `MCP_TOKEN`, `AGENT_TOKEN`, `AGENT_TOKENS` entries) fail closed unless length `>= 24` (`[auth.ts:MIN_TOKEN_LENGTH]`, `[auth.ts:isValidSecretMatch]`) and are compared in constant time via `[auth.ts:sameBytes]`.
  - Site identifiers must match `/^[a-z0-9][a-z0-9_-]{0,31}$/` (`[auth.ts:SITE_ID_PATTERN]`); a shared `AGENT_TOKEN` cannot impersonate any `siteId` declared in `AGENT_TOKENS` (`[auth.ts:authorizeAgent]`), and `agent_hello` payloads cannot overwrite the verified `siteId` attached on `/agent/ws` (`[index.ts:AgentHubDO.webSocketMessage]`).
  - Pre-body auth & rate-limit gates cancel or bound unread request streams before buffering payloads: `/v2/*` & `/compat/*` check `authorizeMcpRequest` before reading bodies (capping pre-auth `/compat/tavily/*` JSON bodies at 64 KiB) (`[compat.ts:handleCompatRoutes]`), `POST /admin/login` checks `oauthStore.checkAuthLockout('admin:' + clientIp)` before reading its 8 KiB-capped form (`[admin.ts:handleAdminRoute]`), OAuth form/JSON bodies are capped at 32 KiB (`[oauth.ts:MAX_OAUTH_FORM_BYTES]`), `/mcp` bodies at 256 KiB (`[mcp.ts:MAX_MCP_REQUEST_BYTES]`), `/v1/ingest-tab` at 4 MiB (`[index.ts:default.fetch]`), and `/fetch` + `/v1/{scrape,extract,interact,agent,jobs}` bodies at `MAX_CALL_UTF8_BYTES` (`1 MiB - 8 KiB`) (`[agent-hub.ts:MAX_CALL_UTF8_BYTES]`, `[index.ts:default.fetch]`).
- **OAuth 2.1, PKCE, Scope & Admin CSRF Security**:
  - Only SHA-256 hashes of authorization codes (90s single-use TTL) and access/refresh tokens (1h / 30d TTLs) are persisted in `OAUTH_SQLITE_SCHEMA` (`[oauth.ts:AUTH_CODE_TTL_MS]`, `[oauth.ts:ACCESS_TOKEN_TTL_MS]`, `[oauth.ts:REFRESH_TOKEN_TTL_MS]`, `[oauth.ts:OAUTH_SQLITE_SCHEMA]`).
  - Refresh token rotation (`rotateRefreshToken`) revokes the entire `grant_id` on replay of an already-rotated token (`kind === 'refresh_used'`), while returning `invalid_grant` without burning the grant if `client_id` mismatches (`[oauth.ts:createSqliteOAuthStore]`).
  - Redirect URIs must be loopback `http://` or owner-allowlisted (`OAUTH_REDIRECT_ALLOWLIST`) external `https://` (`origin !== selfOrigin`) (`[oauth.ts:isValidRedirectUri]`); external redirects force explicit owner token re-entry (`alreadySignedIn: false`) (`[oauth.ts:handleOAuthRoute]`).
  - OAuth bearer tokens on `/mcp` and `/v1/*` must match audience `${origin}/mcp` (`[oauth.ts:authorizeMcpRequest]`), enforcing `'crawl:read'` vs `'crawl:fetch'` tool/route scopes with RFC 6750 `insufficient_scope` step-up challenges (`[mcp.ts:requiredScopeForTool]`, `[mcp.ts:handleMcpRequest]`, `[index.ts:default.fetch]`).
  - `/admin` sessions (`ef_admin_session`) use domain-separated HMAC-SHA256 cookies, server-side logout revocation in dedicated `admin_revocations` (`revoked_admin:<csrf>` pruned strictly by `expires_at <= now`), and constant-time CSRF token checks on `POST /admin/logout` and all `POST /admin/api/*` mutations (`[oauth.ts:OAUTH_SQLITE_SCHEMA]`, `[oauth.ts:verifyAdminSessionCookie]`, `[admin.ts:handleAdminRoute]`).
  - `ACTIVITY_SQLITE_SCHEMA` partitions ring retention into 200 `info` events and 150 `warn`/`error` events so high-volume crawl logs never evict security events (`[activity-log.ts:MAX_INFO_RING_EVENTS]`, `[activity-log.ts:MAX_SECURITY_RING_EVENTS]`), and `auth_failures` caps SQLite buckets at 100 while evicting non-locked IPv6 `/64`-normalized buckets before locked ones (`[oauth.ts:MAX_AUTH_FAILURE_BUCKETS]`, `[safe-input.ts:normalizeClientRateLimitIp]`).
- **SSRF, RFC 9309 `robots.txt` & Ethical Anti-Bypass Rules**:
  - Target URLs, inline `navigate` browser actions, crawl/map seeds, and webhook URLs must be credential-free `https://` on default/443 port passing `isSafePublicHostname` (blocking private/loopback/IPv6 literals, numeric/hex IPv4 TLDs, cloud metadata hosts, DNS-rebinding suffixes, and `selfHost` recursion), re-validated across up to 5 manual redirect hops (`[overflow.ts:isSafePublicHostname]`, `[overflow.ts:validatePublicHttpsTargetUrl]`, `[overflow.ts:validateCallTargetUrls]`, `[overflow.ts:MAX_REDIRECT_HOPS]`).
  - `respectRobots: false` / `robots: false` is rejected (`400 robots_required`) unless every target host matches `ROBOTS_BYPASS_HOSTS` (`'*'` and `'none'` stripped) (`[overflow.ts:validateCallRobotsPolicy]`, `[index.ts:executeHubFetch]`). RFC 9309 `robots.txt` parsing caps downloads at 512 KiB (`[overflow.ts:ROBOTS_MAX_BYTES]`) and fails closed (`unreachable: true`, disallowing crawl) on HTTP 429, 5xx, network timeouts, or disallowed redirects (`[overflow.ts:fetchOverflowRobots]`, `[overflow.ts:isRobotsAllowed]`).
  - Anti-bot challenges, WAF blocks, HTTP 401/403/429, and `robots.txt` disallows are NEVER bypassed: `routeFetchWithFailover` refuses container failover on `400`, `413`, `fat_agent_required`, challenges, or `429` exceeding `maxSeconds` (`[agent-hub.ts:routeFetchWithFailover]`); external SPA fallback (`Crawl4AI`/`Firecrawl`) and Wayback CDX fallback strictly reject WAF/CAPTCHA challenges, `robots.txt` blocks, `login_wall`/`soft_404`/`closed_posting` states, and HTTP `401`/`403`/`404`/`410`/`429` (`[spa-fallback.ts:isEligibleForExternalSpaFallback]`, `[waf.ts:isEligibleForWaybackFallback]`).
- **Coordinator Queueing, Cooldowns & Bounded Streaming**:
  - `AgentHubEngine` acquires per-host locks in lexicographical order with FIFO queue depth capped at 16 (`[agent-hub.ts:MAX_HOST_QUEUE_DEPTH]`), serializes 1 in-flight job per Go agent socket (`[agent-hub.ts:AgentHubEngine.withSiteSlot]`), pins sticky host->site affinity for 30m (`[agent-hub.ts:HOST_STICKY_TTL_MS]`), cools down `429` sites/IPs for `[10s, 60m]` (5m default floor) (`[agent-hub.ts:DEFAULT_429_COOLDOWN_MS]`, `[agent-hub.ts:MAX_COOLDOWN_MS]`), and caps SQLite/memory tracked hosts at 512 (`[index.ts:MAX_SQLITE_TRACKED_HOSTS]`).
  - Linear HTML scanners slice inputs at `MAX_HTML_SCAN_CHARS` (2 MiB) and run in `O(N)` `indexOf` passes without regex backtracking (`[safe-input.ts:MAX_HTML_SCAN_CHARS]`, `[safe-input.ts:replaceHtmlTagBlocksLinear]`); user-supplied regexes in crawl/JSON filters are validated by `compileSafeUserRegex` (<= 160 chars, no backreferences, lookbehinds, stacked quantifiers, or nested quantified alternations) (`[safe-input.ts:compileSafeUserRegex]`).
- **Artifact Verification, Poisoning Resistance & FTS5 Search**:
  - Agent R2 uploads (`PUT /agent/artifacts/:blobSha256`) require an active `(jobId, jobNonce, siteId, requestId)` tuple, per-blob caps of 18 MiB gzipped / 16 MiB uncompressed (`[storage.ts:MAX_ARTIFACT_STORED_BYTES]`, `[storage.ts:MAX_ARTIFACT_CONTENT_BYTES]`), per-job quotas of 400 objects / 128 MiB stored / 512 MiB uncompressed (`[agent-hub.ts:MAX_JOB_ARTIFACT_OBJECTS]`), and exact streamed `SHA-256(gzipBytes) === blobSha256` proof-of-possession before recording in `job.authorizedBlobs` (`[storage.ts:handleAgentArtifactUpload]`, `[agent-hub.ts:AgentHubEngine.dispatchFetch]`).
  - Downstream cache reads (`lookupCachedScrape`, `lookupRevalidationCandidate`), Markdown derivation (`deriveMarkdownDocument` at `SCRAPE_PIPELINE_VERSION = 26`), and FTS5 indexing (`executeIngestPipeline`) never trust unverified content (`isContentVerifiedInMetaD1` must confirm `artifacts.verified_at IS NOT NULL`) (`[ingest.ts:isContentVerifiedInMetaD1]`, `[scrape.ts:SCRAPE_PIPELINE_VERSION]`, `[scrape.ts:deriveMarkdownDocument]`). `verifyStoredArtifact` streams gunzip + SHA-256 verification and never deletes an already-verified or genuine matching blob when a caller supplies mismatched metadata claims (`[ingest.ts:verifyStoredArtifact]`).
  - Scraped Markdown strips invisible Unicode Tag/Bidi smuggling characters (`[scrape.ts:stripInvisibleSmugglingChars]`), optionally scrubs PII (`[scrape.ts:redactPiiText]`), blocks prompt injection (`HTTP 403 SCRAPE_PROMPT_INJECTION_DETECTED`) before LLM calls or R2 writes when `checkPromptInjection` is enabled (`[scrape-advanced.ts:detectPromptInjection]`, `[scrape.ts:executeScrapeCall]`), and binds retained `interact` `sessionId` tokens (`<siteId>.<efsess_id>.<hmac32>`) to the authenticated caller principal (`[scrape.ts:executeInteractCall]`).
  - D1 FTS5 indexing validates `COLLECTION_ID_RE` (`/^[A-Za-z0-9_.:-]{1,64}$/`), batches `<= 46` statements per `db.batch()` (`SEARCH_BATCH_INSERT_LIMIT = 45`), refuses to index `soft_404` or `login_wall` pages (`[ingest.ts:executeIngestPipeline]`), warns at 7 GiB (`WARN_SEARCH_DB_BYTES`) and halts new indexing at 9 GiB (`MAX_SEARCH_DB_BYTES`), and sanitizes all `MATCH` queries via `sanitizeFtsQuery` (`[search-index.ts:D1FtsSearchIndex]`, `[storage.ts:sanitizeFtsQuery]`).
- **LLM API-Key Isolation & Agent Runner Constraints**:
  - `resolveLlmConfig` enforces SSRF validation on custom `baseUrl` overrides (allowing loopback ports `11434`, `1234`, `8000`, `8080` only when `EDGEFETCH_ALLOW_LOCAL_LLM_OVERRIDE === 'true'` or `selfHost` is loopback), never attaches operator API keys when `resolvedOrigin` differs from operator/default provider origins, caps LLM HTTP responses at 4 MiB with `redirect: 'manual'`, and redacts `apiKey` from all logs/traces (`[llm.ts:resolveLlmConfig]`, `[llm.ts:MAX_LLM_RESPONSE_BYTES]`, `[llm.ts:completeLlmTurn]`, `[llm.ts:redactLlmConfigForLog]`).
  - `startOrExecuteAgentCall` enforces `strictConstrainToURLs` (disabling open-web `web_search`/`search_jobs` and restricting `map_site`, `scrape_url`, and `interact_browser` to seed URL prefixes while stripping `navigate` and `executeJavascript` from model browser actions via `SAFE_AGENT_ACTION_TYPES`), clamps step/page budgets (`maxSteps <= 20`, `maxPages <= 40`), and honors `zeroDataRetention` by skipping `inMemoryAgentRuns`, `META` D1 `agent_runs` persistence, and R2/D1 scrape storage (`[agent-runner.ts:startOrExecuteAgentCall]`, `[agent-runner.ts:SAFE_AGENT_ACTION_TYPES]`, `[agent-runner.ts:persistAgentRun]`).
